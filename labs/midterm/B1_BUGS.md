## วิธีกรอก (อ่านก่อนเริ่ม)

กรอกให้ครบ **ทั้ง 6 บั๊ก** · แต่ละบั๊กเขียน 3 อย่างด้วย **คำของตัวเอง** (จะถูกสุ่มถามใน oral)

| คอลัมน์ | ใส่อะไร | ตัวอย่างสิ่งที่เขียน *(บั๊กสมมติ)* |
|---|---|---|
| **ไฟล์ : บรรทัด** | ไฟล์ที่แก้ + เลขบรรทัด | `Foo.jsx : 12` |
| **สาเหตุ** | **ทำไม** มันทำงานผิด (ไม่ใช่แค่ "พิมพ์ผิด") | "ใส่วงเล็บท้ายชื่อฟังก์ชัน เลยถูกเรียกทันทีตอน render" |
| **แก้อย่างไร** | เปลี่ยน**จากอะไร**เป็น**อะไร** | "เอาวงเล็บออก จาก `onClick={fn()}` เป็น `onClick={fn}`" |

## บันทึกของฉัน — กรอกทั้ง 6 บั๊ก

| # | อาการ (ให้มาแล้ว) | ไฟล์ : บรรทัด | สาเหตุ (ทำไมผิด) | แก้อย่างไร |
|---|---|---|---|---|
| 1 | Console เตือนสีเหลืองเรื่องรายการ (list) | `src/components/RequestList.jsx : 9` | ไม่ได้ใส่ prop `key` ให้กับ `<RequestCard />` ในการวนลูป `.map()` ทำให้ React ระบุ element แต่ละตัวใน list ไม่ได้ | เพิ่ม `key={request.id}` ลงใน `<RequestCard />` |
| 2 | ตัวเลข "รอดำเนินการ" ในแผงสรุปไม่ตรงกับที่เห็นจริง | `src/pages/DashboardPage.jsx : 48` | เงื่อนไขการนับของ pending ไปเขียนเป็น `request.status === 'completed'` ทำให้นับจำนวนคำร้องที่เสร็จสิ้นแทน | เปลี่ยนเงื่อนไขจาก `'completed'` เป็น `'pending'` |
| 3 | กดตัวกรอง "รอดำเนินการ" แล้วได้รายการที่ไม่ใช่ | `src/pages/DashboardPage.jsx : 58` | เขียนเงื่อนไขกรองเป็น `request.status !== statusFilter` ทำให้ดึงรายการสถานะอื่นที่ไม่ตรงกับตัวกรองที่เลือกมาแสดง | เปลี่ยนตัวเปรียบเทียบจาก `!==` เป็น `===` |
| 4 | เปลี่ยน URL `REQ-001` → `REQ-002` แล้วข้อมูลไม่เปลี่ยน | `src/pages/RequestDetailPage.jsx : 28` | มีการใช้ `requestId` ดึงข้อมูลใน `useEffect` แต่ไม่ได้ใส่ `requestId` ไว้ใน Dependency Array ทำให้เมื่อเปลี่ยน URL ตัว effect จะไม่ทำงานใหม่ | เพิ่ม `requestId` ลงใน Dependency Array `[requestId, reloadKey]` |
| 5 | กด "ลบ" แล้วรายการยังอยู่ ต้องรีเฟรชถึงหาย | `src/pages/DashboardPage.jsx : 69` | ในฟังก์ชัน `handleDelete` ส่ง `requests` (Array ชุดเดิม) เข้า `setRequests()` แทนที่จะส่ง `nextRequests` หน้าจอจึงไม่อัปเดตใหม่ทันที | เปลี่ยนจาก `setRequests(requests)` เป็น `setRequests(nextRequests)` |
| 6 | กด "Reset Demo Data" แล้วหน้าพัง/ว่างเปล่า | `src/pages/DashboardPage.jsx : 79` | ฟังก์ชัน `resetRequests()` เป็น asynchronous (`async`) แต่ไม่มีคำสั่ง `await` ทำให้ได้ค่าเป็น Promise ไปใส่ใน state แทนที่จะเป็นข้อมูลจริง | ใส่ `await` หน้า `resetRequests()` เป็น `const data = await resetRequests()` |
